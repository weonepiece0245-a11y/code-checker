# 代码检查助手（codecheck）

检查代码 → 在受限环境里实际运行 → 用 AI 讲解错误、给修改建议和修好后的代码 → AI 自动生成测试并逐个运行。

## 功能

- **检查**：找出语法错误、拼错的变量名等问题，并在受限环境里实际运行代码。
- **AI 讲解**：用中文解释错误原因，给出修好的完整代码（可一键“复制”或“放回编辑器”）。
- **AI 生成测试**：AI 读懂代码的用途后设计 5~8 个测试（含边界情况），逐个运行并显示通过/失败。
  修好代码后点“用当前代码重新运行这些测试”，确认真的修好了。
- **打开文件**：从电脑上选择代码文件载入，修改后 Ctrl+S 保存回原文件（覆盖前自动备份到 `.backups`）。
  运行打开的文件时，就像在原位置运行一样：能 `import` / `require` 同一个文件夹里的其他文件，
  `__file__`、报错里的路径和行号都指向原文件（编辑器里没保存的修改也会被运行）。
- **检查文件夹**：一次检查整个文件夹里的 Python / JavaScript 文件（自动跳过 node_modules、.git、虚拟环境等），
  列出每个文件的问题，点问题即可打开文件并跳到那一行。只做静态检查，不会运行文件夹里的代码。
  自动跳过不是你写的文件：浏览器配置文件夹、压缩/打包生成的 JS、`.gitignore` 忽略的文件；
  也可以在报告里点“排除”跳过某个子文件夹（会记住）。
- **AI 审查整个文件夹**：AI 阅读**整个项目的全部文件**，找出逻辑错误、安全隐患、错误处理、性能和结构问题，
  按严重程度排列并给出改法；还会总结写得好的地方和下一步建议。
  - 项目大时自动**分批审查**（每批约 18 万字符，同一文件夹的文件放在一起，最多同时 3 批），
    最后合并所有问题并写出整体总结；页面上显示进度，可以取消。
  - 开始前会告诉你要审查多少文件、分几批、大约要多久。大项目会用掉较多 Claude 额度。
  - 中途失败（比如额度用完）时，已经审完的部分会保存，之后点“继续审查”接着审剩下的文件。
- **确认问题有没有改好**：
  - 每次检查文件夹，都会和上一次的结果对比：已解决几个、还剩几个、新出现几个。
  - **AI 复查**：对照上次 AI 审查的每一条问题，逐条判断“已解决 / 部分解决 / 未解决”，并检查修改有没有带来新问题。
    只重新审查**改动过的文件**（靠每个文件的“指纹”判断）；没改动的文件里的问题直接算“未解决”，不花额度。
- **多个标签页**：像浏览器一样开多个标签页（Ctrl+T 新建、Ctrl+W 关闭、Ctrl+PageDown/PageUp 切换），
  每个标签页各自打开文件或文件夹、各自检查，可以同时进行；正在检查的标签会转圈，有未保存修改的会显示圆点。
- **结果分类显示**：右边按「检查结果 / AI 讲解 / 测试 / 文件夹 / AI 审查」分开，一次只看一类，
  标签上显示简短状态；AI 讲解按小节折叠，AI 审查可以按严重程度筛选。
- **桌面应用**：独立窗口，不用浏览器；关掉窗口即退出。
- **自动更新**：启动时自动更新，或在应用里点“一键更新”。

目前支持的编程语言：**Python**、**JavaScript**。AI 默认用**简体中文**讲解（可以改成繁体中文或英文）。

## Windows 快速开始

1. 安装 [Python](https://www.python.org/downloads/)（3.10 或更高版本），安装时**勾选 "Add python.exe to PATH"**。
2. 检查 JavaScript 代码还需要安装 [Node.js](https://nodejs.org/)（只检查 Python 可以不装）。
3. 把解压出来的文件夹放到一个固定的位置（比如 `D:\code-checker`），然后双击 **`启动网页版.bat`**。第一次运行会自动安装组件，然后自动打开浏览器。
4. 运行一次后，桌面上会出现 **“代码检查助手”** 图标，以后双击它就能打开。
5. 程序会在独立的窗口里打开，用完直接关掉窗口即可。

想用浏览器版：在命令行运行 `启动网页版.bat web`。
启动有问题时，运行 `启动网页版.bat console` 可以在命令行里看到每一步。

## 自动更新

在 `update_source.txt` 里写上 GitHub 仓库（格式：`用户名/仓库名`）。之后每次启动都会检查有没有新版本，有的话自动下载并替换。没联网或文件为空时直接跳过。

## 手动安装

需要 Python 3.10 或更高版本；检查 JavaScript 还需要安装 Node.js。

```bash
pip install -r requirements.txt
```

## AI 怎么接（任选一种）

| 方式 | 怎么设置 | 费用 |
|---|---|---|
| **Claude Code 订阅**（推荐自己用） | 安装 Claude Code，并在终端运行一次 `claude` 登录 | 算在你的 Claude 订阅额度里，不需要 API key |
| **API key** | 设置环境变量 `ANTHROPIC_API_KEY=你的key` | 按调用量付费 |
| 不用 AI | 加参数 `--ai none` | 免费，只有静态检查和运行结果 |

默认是 `auto`：装了 Claude Code 就用订阅额度，没有才用 API key。

## 用法一：命令行

```bash
python -m codecheck examples/buggy.py                  # 示例：拼错变量名
python -m codecheck examples/divide.py                 # 示例：除以零
python -m codecheck examples/buggy.js --ai none        # 不用 AI，速度快
python -m codecheck 我的代码.py --input "5\n3"          # 给程序喂输入
python -m codecheck 我的代码.py --explain-lang English  # 用英文讲解
python -m codecheck 我的代码.py --json                  # 输出 JSON，给其他程序调用
python -m codecheck 我的代码.py --tests                 # 让 AI 生成测试并运行
python -m codecheck 我的代码.py --tests --allow-risky-tests 2,5   # 看过后，允许运行被拦下的第 2、5 个测试
python -m codecheck D:\我的项目                          # 检查整个文件夹
python -m codecheck D:\我的项目 --ai-review              # 再让 AI 审查整个项目
python -m codecheck D:\我的项目 --ai-recheck             # AI 复查：上次的问题解决了没有
```

## 用法二：桌面应用

```bash
python -m codecheck.app
```

## 用法三：网页

```bash
python -m codecheck.web.server
```

然后用浏览器打开 http://127.0.0.1:8765 ，粘贴代码，点“检查”即可。页面里有几个带 bug 的示例可以直接试。

## 运行安全吗？

**“检查”和“AI 生成测试”都会真的运行代码。** 运行方式有两种：

- **本机（不隔离）**：代码就在你的电脑上运行，和你自己双击运行它一样。
  - 有限制：运行时间（默认 5 秒，超时连同子进程一起结束）；Windows 上还限制内存（约 512MB）和进程数量；
    Linux / macOS 上限制 CPU 时间、内存和写入文件的大小。
  - **没有隔离**：代码可以读写、删除你的文件，也可以联网。只运行你自己写的或信任的代码。
  - 第一次在本机运行时会弹窗确认。
- **Docker 隔离（更安全）**：在容器里运行，不能联网、看不到你的文件，超时后容器会被强制停止。
  运行**别人发来、不放心的代码**时请用这个；需要先安装并启动 Docker。检测到 Docker 可用时会默认选它。
  这种方式下，代码不能 import 同一文件夹里的其他文件。

- **AI 写的测试**：运行前会先扫描测试代码。里面有删除文件、联网、执行命令之类的操作时，**先不运行**，
  把测试代码给你看，你确认后才运行（防止被检查的代码里藏着恶意说明，诱导 AI 写出有害的测试）。
  可以只放行你看过的那一个测试，其他有风险的仍然不运行。
  测试如果用到被测代码里导入的模块（比如 `import os as o` 里的 `o`），或者调用了被测代码里
  会读写文件、联网、执行命令的函数，也会先拦下来。

其他保护：

- 只能打开、保存**你自己选过的**文件：用“打开文件”选的文件，或“检查文件夹”选的文件夹里的文件；
  保存只能保存回打开过的那个文件。

- 网页服务只监听本机（127.0.0.1），只接受本应用自己发出、带有本次启动随机令牌的请求，
  其他网页无法调用它来运行代码或读写文件。
- 选了“不用 AI”（`--ai none`）时，任何功能都不会把代码发给 AI；需要 AI 的功能会先提示你。

## 已知限制

- **自动更新没有数字签名。** 它只从 `update_source.txt` 里写的 GitHub 仓库下载，下载后会检查
  （路径安全、版本号一致、文件齐全、程序代码能编译），安装失败会全部还原。但它**相信这个仓库里的代码**：
  如果有人控制了这个 GitHub 账号去改仓库，所有用户下次启动都会装上改动后的代码。
  真正的签名需要有人长期保管一把私钥、每次发布时签名，对这个个人项目来说代价太大，所以没有做。
  请给 GitHub 账号开启两步验证，并且不要把仓库的写权限给别人。
  不想自动更新的话，把 `update_source.txt` 清空即可。
  下载的更新包有大小限制（下载最大 30MB、解压后最大 100MB），正在更新时不会再开始新的检查或审查。
- **本机运行不是沙盒**（见上一节）。

## 项目结构

```
codecheck/
  languages.py     支持的编程语言
  static_check.py  静态检查（不运行就能发现的错误）
  runner.py        受限运行 / Docker 运行
  ai.py            AI 分析（API key 或 Claude Code）
  core.py          把上面几步串起来
  testgen.py       AI 生成测试 + 逐个运行
  folder.py        检查整个文件夹
  folder_ai.py     AI 审查 / AI 复查整个文件夹
  store.py         记住排除的文件夹、上次的检查和审查结果（存在 .userdata）
  textio.py        读取代码文件（自动识别 UTF-8 / GBK）
  files.py         打开 / 保存文件、选择文件对话框
  app.py           桌面应用窗口
  updater.py       自动更新
  deps.py          检查和安装组件
  launcher.py      无黑色窗口的启动器（启动画面 + 更新 + 安装组件 + 打开窗口）
  cli.py           命令行
  web/             界面（桌面应用和网页版共用）
examples/          带 bug 的示例代码
```
